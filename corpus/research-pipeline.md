# Research pipeline notes

A multi-stage research system breaks a hard question into smaller sub-questions.

Typical stages:
1. Plan — split the query into 2–4 sub-questions.
2. Research — search the web and local documents, extract short findings.
3. Normalize — merge findings into one draft.
4. Verify — check the draft against findings (pass or revise).
5. Final — write the user-facing report.

Document search looks inside local files (this corpus folder). Web search uses an external API (Tavily).
